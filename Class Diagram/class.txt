1. User

Responsibility:
The User class represents a candidate who interacts with the system. It handles basic user-related operations such as registration, authentication, and participation in interviews.

Attributes:

userId : String — uniquely identifies each user

name : String — stores the user’s name

email : String — used for login and communication

password : String — stores encrypted login credentials

Methods:

register() : void — allows a new user to create an account

login() : boolean — verifies user credentials

uploadResume() : void — enables the user to upload a resume

attendInterview() : void — allows the user to take part in an interview session

2. Resume

Responsibility:
The Resume class stores and manages resume-related information submitted by the user. It also supports parsing and extracting useful skills from the resume content.

Attributes:

resumeId : String — uniquely identifies the resume

content : String — stores the raw resume text

parsedSkills : List<String> — contains skills extracted from the resume

Methods:

parseResume() : void — analyzes resume content

getSkills() : List<String> — returns the extracted skill set

3. Interview

Responsibility:
The Interview class manages the interview process, including storing questions and recording user responses.

Attributes:

interviewId : String — uniquely identifies the interview session

questions : List<String> — stores interview questions

answers : List<String> — stores the user’s responses

Methods:

startInterview() : void — initiates the interview session

submitAnswers() : void — records submitted answers

4. AIEngine

Responsibility:
The AIEngine class performs intelligent analysis of resumes and interview responses using AI models. It acts as the core evaluation component of the system.

Attributes:

modelName : String — specifies the AI model being used

Methods:

analyzeResume(resume : Resume) : Feedback — evaluates the resume

evaluateInterview(interview : Interview) : Feedback — scores interview responses

5. Feedback

Responsibility:
The Feedback class stores the evaluation results generated by the AI engine and provides structured feedback to the user.

Attributes:

score : float — represents the evaluation score

remarks : String — contains qualitative feedback

Methods:

generateFeedback() : void — prepares feedback data

getScore() : float — returns the final score

6. AuthService

Responsibility:
The AuthService class is responsible for authenticating users and validating login credentials before granting access to the system.

Attributes:

authToken : String — represents the authentication token

Methods:

authenticate(email : String, password : String) : boolean — verifies user credentials

Visibility Explanation

Private (-) members are used for attributes to ensure data security and prevent direct external access.

Public (+) methods are provided to allow controlled interaction with the system’s functionalities.
